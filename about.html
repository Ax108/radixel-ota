Radixel

Integer calculator · live base conversion · bitwise editor

Radixel is a mobile calculator built for programmers, students, and anyone who works with integers across number bases. It combines a full expression calculator with a dedicated bitwise editing mode — both operating on the same underlying value.

What Radixel does

Radixel helps you evaluate integer arithmetic, inspect values in decimal, binary, octal, and hexadecimal at the same time, and perform word-sized bitwise operations with clear overflow feedback. All calculations stay on your device. Radixel does not require an account, does not show advertisements, and does not sell personal data.

Calculator tab

  • Enter expressions with digits, operators (+ − × ÷), and parentheses.
  • View the live result in four bases at once: DEC BIN OCT HEX
  • Select an input base so the keypad accepts the correct digit set (for example, hex letters A–F when HEX is active).
  • Use Ans to insert the last evaluated result, and = to evaluate with standard operator precedence.
  • Copy any base row to the clipboard in raw or prefixed format (for example 0x6F, 0b01101111).
  • Integer-only by design — fixed word-size semantics apply across all bases.

Bitwise tab

  • Configure word size (8, 16, 32, or 64 bits) and signed/unsigned interpretation.
  • Edit individual bits in a visual grid, or enter values directly on a hex keypad.
  • Apply bitwise operations: AND, OR, XOR, NOT, shifts (<<1, >>1), and two's-complement negate.
  • Share the same value with the Calculator tab — changes in either tab are reflected immediately in the other.

Settings & history

  • Choose light or dark appearance.
  • Set defaults for word size, sign mode, and copy format on launch.
  • Review a local history of past calculator and bitwise operations (stored on your device, capped at 300 entries per category).
  • Reset the app to clear session state, preferences, and history.

Over-the-air (OTA) updates

Radixel uses a self-hosted JavaScript update channel powered by Expo Updates. This is not Expo Application Services (EAS) Update. Updates are published to this GitHub Pages CDN and checked when you open the app while online. Only the JavaScript layer of the app may be updated this way; native permissions and store-distributed binaries are unchanged until you install a new version from the App Store or Google Play.

For full details on what is collected during update checks, see our Privacy Policy.
